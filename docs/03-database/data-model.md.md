# Модель данных LifeOS

**Статус:** Черновик  
**Версия:** 0.1  
**Последнее обновление:** 2026-08-09

## 1. Назначение

Этот документ определяет логическую модель данных LifeOS.

Он описывает:

- основные сущности;
- общие свойства сущностей;
- связи между сущностями;
- жизненный цикл данных;
- AI-предложения связей;
- правила удаления и архивирования;
- принципы владения и контекста данных.

Документ не определяет конкретную реализацию базы данных.

Физическая структура базы данных будет спроектирована отдельно после утверждения логической модели.

---

# 2. Основной принцип

LifeOS строится вокруг сущностей и связей между ними.

Основная идея:

> **Сущность существует самостоятельно. Связи добавляют ей контекст, но не определяют её существование.**
